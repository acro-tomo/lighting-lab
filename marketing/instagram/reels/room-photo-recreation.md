# リール構成案｜フリー素材の部屋を再現して、照明を差し替える

**狙い**: 「同じ部屋のまま条件を1つだけ変えた画が無限に作れる」というこのアカウントの強みを、
**外部の写真を出発点にする**ことで初見の人に一発で伝える。
写真アカウントが真似できない画であることを、写真そのものと並べて証明する。

運用方針は [docs/instagram-playbook.md](../../../docs/instagram-playbook.md)、
画づくりの実寸仕様は [marketing/instagram/README.md](../README.md)。

---

## 1. 推奨構成 A｜「昼の写真しかない部屋の、夜を見る」

全22.0秒・7ショット。冒頭2秒で写真から3D再現へ切り替わること自体をフックにする
（プレイブック2の「冒頭3秒で約45%離脱」に対し、切替という視覚イベントを最初に置く）。

採用写真が昼のカットだったため、当初の「写真→夜の再現→照明差し替え」から組み直した。
施主が持っている部屋の写真は内覧写真もカタログもほぼ全部昼間で、**夜だけが分からない**。
その昼夜の切り替え（`s3-night`）を第2の山に置いている。読み取りメモは
[room-photo-recreation.source.md](room-photo-recreation.source.md)。

| id | 尺 | 画 | eyebrow | headline | sub | voice |
|---|---|---|---|---|---|---|
| `s1-photo` | 2.0s | 採用写真（昼）。左下に撮影者クレジット | フリー素材の部屋 | この部屋の / 夜を見たい | 写真：Pexels | この部屋、昼の写真しかない。 |
| `s2-recreate` | 2.5s | 同アングルの3D再現（日光ON・昼）へ 0.6s クロスフェード | 3Dで再現 | まず / 作り直す | 間取り・天井高・家具の位置を合わせた | 同じ部屋を作りました。 |
| `s3-night` | 3.5s | アングル固定で日光を落として夜へ | 昼 → 夜 | 夜は / こうなる | 写真では見られない画 | 夜にすると、こう。 |
| `s4-temp` | 4.0s | 2700K → 5000K スイープ | 2700K → 5000K | 色だけ / 動かします | 器具も配置も変えていない | ここから、色を変えます。 |
| `s5-count` | 4.0s | ダウンライト2灯 → 6灯＋間接（上下スタック比較） | 2灯 → 6灯＋間接 | 灯を / 足す | 明るさより、影の出方が変わる | 灯を足して、間接を入れる。 |
| `s6-yours` | 3.0s | 2Dの間取り図 → 3Dへ切り替わる画 | あなたの部屋でも | 間取り図を / 入れるだけ | PNG・PDFの間取り図から作れる | 同じことが、自分の間取りでできます。 |
| `s7-outro` | 3.0s | outro 版（レンダーを不透明度0.22で敷く） | 登録なし・ブラウザだけ | 保存して / 打ち合わせに | lighting-lab-46l.pages.dev | 保存して、打ち合わせに。 |

- headline は全行13文字以内・最大2行（プレイブック6-2）。
- 尺を詰めるなら `s5-count` を落として18.0秒版にする。`s2-recreate` と `s3-night` は削らない（企画の核）。
- `s5-count` は元の部屋がダウンライト2灯なので、**減らす方向ではなく足す方向**で比較する。
- 音声はショット単位で作る。1本の長い読み上げを後から重ねない（[README](../README.md#リールにai音声を入れる)）。

## 2. 別案

| 案 | 構成 | 向き / 弱点 |
|---|---|---|
| **B｜3部屋を連続再現** | 写真3枚を各6秒で「写真→再現→1条件変更」 | 再現力を数で示せる。ただし1枚目の写真で判断されるためフックはAより弱く、1条件しか見せられない |
| **C｜種明かし型** | 自前レンダーから始め、2秒後に「これ、この写真から作りました」と写真を出す | フックは最も強い。ただし視聴者が自分ごと化するまで時間がかかる。Aが伸びたら表紙違いのA/B用に回す |

まずAを1本出し、View数が取れたらCで型を検証する。

## 3. フリー素材の選定基準

再現の難易度と説得力を決めるのはここ。次を全部満たす写真だけ使う。

- **部屋の全景が写っている**。最優先。器具のクローズアップは、再現しても映るのが
  照明器具のモデリングになってしまい、間取りの話にならない
- **夜、または照明が点いている**。昼光メインの写真だと主題（照明）がズレる
- **1点透視に近い**。床と天井のラインが両方見えるとカメラ合わせが早く済む
- **人物・ペット・ブランドロゴ・壁のアート作品が写っていない**（Pexels/Unsplashともに被写体権利は別扱い）
- **家具がカタログ品で代替できる形**。造作だらけの部屋は再現が寄らず逆効果になる
- **4:5 / 9:16 にクロップしても構図が壊れない**
- 出典は Unsplash か Pexels。工務店・メーカーの施工写真は使わない（プレイブック8）

## 4. ライセンスの扱い

Unsplash License / Pexels License はいずれも商用利用可・クレジット不要だが、
**写真そのものを主要コンテンツとして再配布すること**は両者とも禁じている。
今回は「比較対象として数秒引用し、自前レンダーと対で見せる」用途なので範囲内だが、
グレーに寄せないため次の3点を必ず守る。

1. 写真のフルスクリーン露出は **2秒以内**、かつ必ずテロップを重ねた状態で出す
2. 画面内に撮影者クレジットを小さく置く（`Photo: <name> / Unsplash`）
3. キャプション末尾にも出典を1行入れる

## 5. プレイブックとの衝突（決着済み）

[docs/instagram-playbook.md](../../../docs/instagram-playbook.md) の 6-5 に
「画像は必ず自分のレンダー。フリー素材を混ぜた瞬間にアカウントの独自性が消える」がある。
この企画は正面から当たる。

ただしこのルールの意図は「フリー素材で世界観を作らない」ことで、
本企画は写真を**お題**として使い、見せる答えは全部自前レンダー。趣旨には反しない。
プレイブック側に例外を1行足すのが妥当。

[プレイブック6-5](../../../docs/instagram-playbook.md) に例外条項を追記済み。条件は3つ。

1. 写真の露出は2秒以内
2. 必ず自前レンダーと対で使う
3. 撮影者クレジットを画面とキャプションに入れる

表紙（カバー）は例外の対象外で、引き続き自前レンダーにする。

## 6. 実装に必要な差分

既存の [capture-decision-reel.mjs](../../../scripts/instagram/capture-decision-reel.mjs) は
全ショットがアプリのcanvas撮影で、外部画像を扱えない。追加が要るのは次の2点だけ。

| 項目 | 内容 |
|---|---|
| `sequence.mode: "still-image"` | 設定の `imagePath` を `ffmpeg -loop 1` で指定尺のフレーム列に展開する。`s1-photo` 用 |
| `sequence.mode: "daylight-fade"` | `daylight` の強度を補間して昼から夜へ落とす。`s3-night` 用。既存の `light-property-animation` と同じ作りで、動かす対象が日光になるだけ |
| ショット単位の xfade 長 | 現在 [encode-reel.mjs](../../../scripts/instagram/encode-reel.mjs#L225) の xfade は全クリップ一律。写真→再現だけ 0.6s にしたいなら per-shot 指定を足す。一律のままでも成立はする |

`s3` は既存の色温度スイープ、`s4` は `stacked-light-compare`、`s5` は調光値のアニメーションで、
いずれも既存モードの範囲か小さな拡張で足りる。

**カメラ合わせは手作業**。アプリに参照画像を3Dビューへ重ねる機能は無い
（[types.ts](../../../src/types.ts#L304) の背景画像は2D間取り専用）。
再現後のスクリーンショットと写真を画像編集で重ね、`camera.fov` / `position` / `target` を追い込む。
写真は広角で撮られていることが多いので fov は 70〜80 あたりから始める。

## 7. 制作手順

`still-image` モード追加後、別ターミナルで `npm run dev` を起動して実行する。

```bash
# 構図確認（3フレームだけ）
REEL_CONFIG=marketing/instagram/reels/room-photo-recreation.reel.json REEL_SMOKE=1 npm run ig:decision-capture

# 本撮影 → 音声 → エンコード
REEL_CONFIG=marketing/instagram/reels/room-photo-recreation.reel.json npm run ig:decision-capture
python3 scripts/instagram/generate-reel-voice.py marketing/instagram/reels/room-photo-recreation.reel.json
REEL_CONFIG=marketing/instagram/reels/room-photo-recreation.reel.json REEL_WITH_VOICE=1 npm run ig:decision-encode
```
