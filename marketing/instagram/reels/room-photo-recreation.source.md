# 採用写真の読み取りメモ

ローカル配置先: `marketing/instagram/refs/pexels-15580493.jpg`

写真を見て起こした再現用のメモ。**寸法はすべて目視の推定**で、実測ではない。
広角レンズで撮られているため実際より広く見えている可能性が高く、
再現時は下の値を出発点にして、消失点が合うまで詰める。

## 部屋

| 項目 | 推定 | 根拠・注意 |
|---|---|---|
| 幅（左右） | 5.5m | L字ソファを2.5m級として逆算。広角の歪みで過大評価しやすい |
| 奥行き | 7.0m | 奥の窓壁までかなり深い。6.5〜7.5mの幅で調整する |
| 天井高 | 2.6m | 腰のモールディングが床から約0.9m。米国住宅の 8ft(2.44) / 9ft(2.74) の中間に見える |
| 壁 | 明度中のグレー。白の巾木・窓枠・チェアレール | チェアレール（腰の見切り）は再現困難。**省略でよい** |
| 床 | 濃い茶の木目フローリング | |
| 天井 | 白。点検口らしき四角（左奥）と空調グリル（右奥） | どちらも省略でよい |

## 開口

- 奥壁: 縦長窓2つ（横型ブラインド）
- 右壁: 大きめの窓1つ（同上）
- 左奥: 開口＋グレーのドア（別室へ抜ける）
- 左手前: 袖壁の開口。ここが画面左端の縦ラインを作っている

## 照明（写真の時点）

| 器具 | 数 | 状態 |
|---|---|---|
| シーリングファン一体ライト | 1 | 点灯 |
| ダウンライト | 2 | 消灯に見える（天井中央やや奥） |
| フロアランプ（黒・アーム型） | 1 | 消灯。右手前 |

**主光源は窓からの昼光**。つまりこの写真は照明の写真ではない。構成の組み直しが要る（後述）。

シーリングファンが器具カタログにあるかは未確認。無ければシーリングライトかペンダントで
代替するか、ファンは省略する。**専用モデルは足さない**（プロジェクトの方針）。

## 家具

L字ソファ（グレー・3人＋チェイス）／オットマン／花柄クッション4／幾何柄ラグ（白×チャコール）／
木製TVボード（ミッドセンチュリー脚）＋TV＋サウンドバー／黒フレームの姿見（床置き）／
黒の細脚サイドテーブル／観葉植物（サンスベリア）

いずれもカタログの既製オブジェクトで寄せられる見込み。柄物（クッション・ラグ）は
無地で代用してよい。夜のシーンでは柄はほとんど効かない。

## カメラ

- 左手前の角から対角に向けた**2点透視**。1点透視ではないのでカメラ合わせは一手間かかる
- アイレベルは低め。床から 1.1〜1.3m（不動産撮影の定石）
- 広角。四隅で直線が伸びている。`fov` は 75〜85 から始めて詰める

## 構成への影響（重要）

昼の写真なので、当初の構成（写真 → 夜の再現 → 照明差し替え）はそのままでは繋がらない。

ただしこれは弱点ではなく、**むしろ企画を強くする**。施主が持っている部屋の写真は
内覧写真もカタログもインスタの憧れも、ほぼ全部昼間で、**夜の見え方だけが分からない**。
「昼の写真しかない部屋の、夜が見える」は写真アカウントに作れない画で、悩みにも直結している。

構成は「昼の再現 → 夜に切り替える」を主役に組み直した。
