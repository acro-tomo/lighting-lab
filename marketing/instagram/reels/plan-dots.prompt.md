# 次のリール制作プロンプト｜配灯図の●（plan-dots）

Claude Code に貼って1本作らせるためのプロンプト。設計の根拠と差し替え候補は下段にある。

**この版での画の前提**: 常駐パストレ（リアル表示）と最終レンダーPNGは、まだ収束前の粒状が残るため**使わない**。
撮影はラスター編集表示のまま行い、主役は2D平面図とUIの数値に置く。3Dは短い引きのカットに限定する。

---

## コピペ用プロンプト

```
LDK Lighting Lab の Instagram リールを1本作る。企画は決まっているので、設定ファイルの作成・
撮影スクリプトの拡張・撮影・音声生成・エンコードまでを通してやる。

## 誰に向けた動画か（ターゲット）

- 30代前半〜40代。注文住宅・建て替え・リノベを検討中の施主。
- 時期は着工前〜電気打ち合わせ前の3〜6ヶ月。照明を決め切る直前がピーク。
- 夫婦2人で決める。片方が見つけて、もう片方や営業担当にDMで送る動きを狙う。
- 「照明シミュレーター」を探している人ではない。「照明計画 後悔」「ダウンライト 多すぎ」
  「電球色 昼白色 どっち」を調べている人。

## そのターゲットは何に困っているか

1. 電気打ち合わせで渡されるのは、間取り図に照明記号（●）が並んだ配灯図だけ。
   ●が8個並んでいても、それが多いのか少ないのかを判断する材料がない。
2. 明るさ・色温度・調光は数値（lm / K / %）で示されるが、数値と夜の部屋の雰囲気が結びつかない。
3. 決めるのは30分の打ち合わせ、住むのは何十年。しかも配線は着工後に変えられない。
4. 「これで大丈夫ですか」と聞かれても、比較対象がないので頷くしかない。

## このアプリでどう解決するか（動画で見せる解決）

- 自分の間取り図（PNG/JPG/PDF）を取り込み、同じ部屋・同じ家具のまま**条件を1つだけ**変えて並べられる。
- 灯数、位置、明るさ、色温度、調光、間接照明の有無を切り替えて、部屋の雰囲気の差として見られる。
- 比較画像を保存してPNGで書き出せるので、打ち合わせにそのまま持っていける。
- 登録なし・ブラウザだけで動く。
- ただし雰囲気比較用の視覚シミュレーションであり、実照度(lux)・配光・施工後の見え方は保証しない。
  この一線は動画・キャプションの両方で守る。

## 動画仕様

- 縦 1080×1920 / 30fps / 全体21〜23秒 / 5ショット。
- 音声は AivisSpeech でショット単位に生成する（1本の長尺読み上げを後から重ねない）。
  話者・話速は marketing/instagram/reels/six-rooms.reel.json と同じ値を使う。
- 音声がショットの尺を超えたら、話速を上げずに台本を削るか尺を延ばす。

## 最初の3秒（ここが成否の大半）

リールは冒頭3秒で約45%が離脱する。次を満たすこと。

- 1カット目は**配灯図そのもの**。黒画面から間取りの線が出て、照明記号の●が並ぶ。
  打ち合わせで実際に見せられる紙と同じ絵にして、0.5秒で「自分ごと」にする。
- テロップは結論を先に言い切る:「照明は この丸だけで 決まる」。
- ツール名・ロゴ・UI全体像を最初に出さない。ツールが主語になった瞬間にスキップされる。
- 動きは1つだけ（●が順に灯る）。カメラは動かさない。

## 使う画・使わない画

使う:
- 2D平面図（SVGなので拡大してもシャープ）。
- インスペクターのUIと数値。
- ラスター編集表示の3D。引きの構図、明暗差の大きい絵、1カット5.5秒以内。

使わない:
- 常駐パストレ（リアル表示）と最終レンダーPNG。収束前の粒状が残るため今回は一切使わない。
- 素材の質感やディテールに寄るクローズアップ。
- 静止した「完成画」を主役にする構成。差分（切り替わり）で見せる。

## テロップ規則

- 1行あたり全角13文字以内、最大3行。1画面で主張は1つ。
- 配色は marketing/instagram/README.md のブランド値（ベース #070706 / インク #F2EDE1 /
  アンバー #F5C64D / クール #9BBEDD）。昼白色・昼光色側のラベルだけ accent: "cool"。
- 免責はoutroに入る。全ショットに出す場合は設定ファイルの disclaimer を設定する。

## 禁止

- 実照度(lux)・IES/LDT配光・照度計算書を保証する表現。「◯◯lux確保できます」は書かない。
- 「これで失敗しない」等の断定コピー。
- 他社製品名・メーカー型番での比較。施工写真の転載。
- フリー素材。画は全部このアプリで作ったものにする。

別ターミナルで npm run dev を起動した状態で、次の順に実行する。

    REEL_CONFIG=marketing/instagram/reels/plan-dots.reel.json REEL_SMOKE=1 npm run ig:decision-capture
    REEL_CONFIG=marketing/instagram/reels/plan-dots.reel.json npm run ig:decision-capture
    python3 scripts/instagram/generate-reel-voice.py marketing/instagram/reels/plan-dots.reel.json
    REEL_CONFIG=marketing/instagram/reels/plan-dots.reel.json REEL_WITH_VOICE=1 npm run ig:decision-encode
```

## フックの差し替え候補（伸びなかったときに1本ずつ試す）

| 案 | 1カット目 | テロップ | 狙い |
|---|---|---|---|
| A（本命） | 配灯図の●が順に灯る | 照明は／この丸だけで／決まる | 打ち合わせで見た紙と同じ絵。自分ごと化が最速 |
| B | 時計と図面 | 決める時間30分／住むのは30年 | 数字の対比。損失回避に効く |
| C | 天井が暗い部屋 | 夜だけ／後悔する | 後悔系フックの直球。既存投稿と被るので3本目以降 |

判断材料は表紙パターン別のView数。1本ずつ違う型で出して、勝った型に寄せる。

## この構成にした理由

- Instagram運用プレイブックの「悩みを主語に、ツールは答えの見せ方として黙って映す」に合わせた。
  1カット目にUI全体像を出さないのはこのため。
- 比較リール（週2本・リーチ担当）の枠。同じ部屋のまま条件を1つだけ変える画は写真アカウントには
  物理的に作れない。この差分がアカウントの強み。
- 配灯図は施主が実際に受け取る唯一の資料で、「●だけで決めさせられている」構図は共感と不安を同時に作る。
  夫婦間・営業担当へのDM送信（リーチ拡大の最重要シグナル）が起きやすい題材でもある。
- ブックエンド（1カット目と最終カットを同じ2D平面図にする）でループ再生時の接続が滑らかになり、
  視聴維持が伸びる。

## 実装で引っかかる点

- 2D平面図を撮るモードは現状のスクリプトに無い。3ショットがこれに依存するので、着手は
  scripts/instagram/capture-decision-reel.mjs の拡張から。
- 等間隔8灯グリッドは既存の stacked-light-compare（`replaceLights` の xs / zs）で作れる。
  平屋デモ（12.0×7.2m）なら xs 4点 × zs 2点で8灯になる。
- 平屋デモは日光OFF・夜の状態で保存済みなので、読み込んだ直後の画がそのまま使える。
