## ターゲット

**間取りが確定し、電気図面（照明配置図）の打ち合わせが目前か、終わったばかりの施主。**

- 注文住宅かフルリノベ。30〜40代。`#マイホーム計画中` `#家づくり記録` を追っている
- 色温度・多灯分散といった**一般論はすでに見終わっている**。次に詰まるのが
  「一般論は分かった。で、うちの間取りではどうなるのか」
- 決裁の期限がある。照明の打ち合わせは1〜2回で、着工後は配線位置を動かせない。
  この期限が行動の動機になる

**狙わない人**: 照明の基礎知識を集めている段階の人、インテリア写真を眺めたい人、
夜景の雰囲気だけを求める人。前者には既存のカルーセルがある。

## 見せ方

### 1本1判断

1本で扱う判断は1つだけ。**AかBか**で提示し、Bが正解とは言わない。
判断の中身は「条件次第で変わる」であって、答えではない。

比較を成立させるため、変える条件は1つに絞り、合計光束（`lumens × dimmer / 100` の総和）を
バリアント間で揃える。揃えないのは「足すか足さないか」自体が判断のときだけ
（縁側リールがこれ）。揃えた差は0.1%以内に収める。

### 4ショット構成（合計17秒前後）

| # | 尺 | 役割 | 中身 |
|---|---|---|---|
| s1 | 3.4s | **フック** | 全体の35〜40%地点、つまり**再生1.3秒付近でバリアントを切り替える**。説明より先に絵を変える |
| s2 | 5.8〜6.0s | 判断の提示 | カメラを寄せながらもう一度切り替える。「変えたのはこれだけ」を明示 |
| s3 | 5.0s | A/B/A | カメラ固定で3回切り替え、差だけを見せる |
| s4 | 3.8s | CTA | 「自分の間取り図で試せる」。免責を残したまま締める |

**最初の2〜3秒に必ずインパクトを置く。** 静止した説明カットから始めない。
以前の構成はs1が3.6秒の静止説明で、変化が始まるのが4秒目だった。これをやめた。

### 冒頭3秒の規約（2026-08-18 確定・最優先）

**3秒以内に「何の動画か」が伝わらないものは作らない。**これが他のどの規約よりも優先する。

第4弾で導入した「冒頭2秒にテロップもロックアップも出さない」は撤回する。理由は3つ。

1. **根拠が無い。**「効くから」ではなく「他に触る変数が無いから」導入された（上の見直しの節）。
2. **効果を測っていない。**再生維持率を31本分いちども見ていない
   （[PLAN-3reels.md](PLAN-3reels.md):102）。冒頭で落ちているかすら分かっていない。
3. **この文書自身と矛盾する。**上の「最初の2〜3秒に必ずインパクトを置く」を満たしていない。
   静止した説明カットを避けるはずが、何を見ているか分からない画から始まる作りになっていた。

**そもそも実装されていない。**`encode-reel.mjs:196` の
`manifest.shots.filter((shot) => TEXTS[shot.id])` は、テロップの無いショットを無音にするのではなく
**丸ごと落とす**。無音ショットを出すには別途実装が要り、それは入っていない。

#### 差し替える型

| 時点 | 満たすこと |
|---|---|
| 0.0秒 | **2つの状態が既に画面にある。**1枚の絵から始めない |
| 0.0秒 | **テロップが1行出ている。**説明ではなく対象の名指し。全角14文字以内 |
| 0.0〜0.5秒 | **動きが始まっている。**静止フレームで始めない |
| 〜3.0秒 | 「これは自分の家の照明を選ぶ話だ」と「何の場所か」が伝わっている |

全画面の1案から始めて0.5秒で上下に割れ、2案目が入る形が最も速い。
比較の動画であることが0.5秒で伝わり、かつ静止で始まらない。

#### 既存機能だけで組める

新規実装は要らない。

- 上下2分割: 撮影側の `stacked-light-compare` モード
  （`scripts/instagram/capture-decision-reel.mjs:354-356, 457`）が上下それぞれを通しで撮って vstack する
- 分割線: `encode-reel.mjs:144` の `.split-rule` が `top: 959px` に引かれる
- 上下のラベル: `text.visual.kind = "split"` の `topLabel` / `bottomLabel`
  （`encode-reel.mjs:78-81`）。**0秒で「何と何を比べているか」を言うのはここが最短**
- 分割時のテロップ位置: `.text.split-text { right: 420px; }`（`:134`）で調整済み

#### 測ること

この型に変えたら、**Instagram Insights の再生維持率を必ず読む。**
31本作って一度も見ていない指標なので、冒頭を直したかどうかに関わらず先に見る価値がある。

- 1秒で半減しているなら、冒頭の型が正しい打ち手
- 最後まで見られているのに保存もシェアも0なら、直すべきは冒頭ではなく**動画の後の動線**

どちらなのかを判別せずに次の6本を作ると、また検証されない仮説が1つ増える。

### テロップと構図

- テロップは 1080×1920 の **y=1000〜1500** に載る。被写体をこの帯に置くと文字で隠れる
- カメラは見下ろし気味にして、**主役を画面の上半分（y<1000）**に収める。
  天井が主役なら見上げず、ピッチを下げて天井を上半分へ持ち上げる
- 音を切っても判断が伝わること。ナレーションは理解の必須条件にしない
- ナレーションは実測 **5.8字/秒**。ショット尺−0.4秒（xfade分）を超えると音声生成が止まる

### 言葉づかい

- 画面で実際に起きていることだけを言う。**描画を見る前に台本を書かない**
- 「これが正解」と言い切らない。判断の分岐を示して終わる
- 実照度(lux)・IES/LDT配光・照度計算書を保証する表現を入れない
- 免責の焼き込みと、キャプション末尾の免責2行は毎回入れる

## 実績による見直し（2026-08-14 追記）

リール21本の実績（累計リーチ1946・保存4・シェア0・コメント0・フォロー0）を読み直した結果、
**この文書の「4ショット・17秒前後」構成は第4弾では採用しない**。詳細と数字は
[next-four-reels.md](next-four-reels.md) 1節。要点だけ:

- 17秒群（13本）の平均リーチ94.6に対し、9〜13秒群（6本）は119.3。差は小さく n=6 だが、
  短くするコストはゼロ。第4弾は9〜12秒で作る。
- s1で再生1.3秒付近にバリアント切替を置く改善は既に入っているのに、リーチが動いていない。
  次に触れる変数として**冒頭2秒にテロップもロックアップも出さない**を試す。
  → **2026-08-18 撤回。**下の「冒頭3秒の規約」を参照。
- 尺を9〜12秒にすると1ショット1.5〜2.0秒になり、5.8字/秒では6字前後しか入らない。
  **第4弾は無音**。ナレーション前提の尺設計はここでは使えない。
- リーチが103〜126に固定されているため、**1本ごとの創作の良し悪しは統計的に判別できない**
  （保存率0.2%・リーチ110なら1本あたりの期待保存は0.22件）。第4弾は「保存が増える」ことを
  狙って作るのではなく、一度も動かしていない変数を1本ずつ入れるために作る。

この文書の他の規約（1本1判断、合計光束を揃える、テロップ帯 y=1000〜1500 と主役を上半分に置く構図、
言い切らない、免責）は第4弾でもそのまま守る。
