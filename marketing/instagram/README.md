# Instagram サムネイル生成

`out/` の PNG がそのまま投稿できる完成物。運用方針は [docs/instagram-playbook.md](../../docs/instagram-playbook.md)。

## 使い方

```bash
# 1. フォント取得（初回のみ / fonts/ は .gitignore 済み）
npm run ig:fonts

# 2. 背景プレートをアプリから撮る（別ターミナルで npm run dev を起動しておく）
npm run ig:plates

# 3. サムネイルを書き出す
npm run ig:thumbs

# セーフゾーンのガイド線入りも一緒に出す（入稿前の確認用）
npm run ig:thumbs -- --guides

# 特定の1枚だけ作り直す
npm run ig:thumbs -- 02-warm-vs-cool
```

文言やレイアウトを変えるときは [`scripts/instagram/thumbnail-designs.mjs`](../../scripts/instagram/thumbnail-designs.mjs)
の `DESIGNS` を編集する。ここだけで完結する。

## ディレクトリ

| パス | 中身 | git |
|---|---|---|
| `out/` | 完成サムネイル（投稿するのはこれ） | コミットする |
| `plates/` | アプリから撮った背景レンダー | コミットする |
| `fonts/` | Google Fonts の TTF | 除外（スクリプトで再取得） |

## サイズとセーフゾーン

| format | 実寸 | 用途 | 注意 |
|---|---|---|---|
| `feed` | 1080×1350 | フィード投稿・カルーセル表紙 | 4:5。フィードで最も面積が大きい |
| `reel` | 1080×1920 | リールのカバー | **プロフィールグリッドで 3:4 に切られる**。文字は中央 1080×1080 に収める |
| `square` | 1080×1080 | カルーセルの中ページ | |

`reel` はレンダラが上下 420px を空けて文字を中央に寄せる。`--guides` で
黄色の破線（セーフゾーン）と青線（3:4 クロップ位置）を重ねた確認用画像が出る。

## デザイン仕様

### 配色

アプリ本体（`src/styles.css`）と同じ値を使う。フィード全体が製品と地続きに見えるのが狙い。

| 役割 | 値 | 使いどころ |
|---|---|---|
| ベース | `#070706` | 背景・帯 |
| インク | `#F2EDE1` | 見出し（暖色寄りの生成り。純白は使わない） |
| アンバー | `#F5C64D` | アイキャッチ、ロゴマーク、電球色側のラベル |
| クール | `#9BBEDD` | 昼白色・昼光色側のラベル、寒色トーンの投稿 |

**なぜ暗い暖色か**: 住宅系のフィードは白基調・自然光の写真で埋まっている。
黒背景＋電球色はスクロール中に明確に浮くうえ、扱っている題材（夜の照明）と一致している。

### フォント

| 用途 | フォント | ウェイト |
|---|---|---|
| 見出し | Zen Kaku Gothic New | 900 |
| 補足 | Zen Kaku Gothic New | 500 |
| アイキャッチ（小見出し） | Shippori Mincho B1 | 700 |
| 数字・英字・ラベル | Inter | 700 / 900 |

明朝を細く広い字間で1行だけ入れると、ゴシックだけの構成より一段「照明・インテリア」の文脈に寄る。
Inter はアプリ本体の UI フォントと同じ。

### 文字量の上限

- 見出しは **1行あたり全角13文字以内・最大3行**。スマホの一覧では約120px幅で表示される。
- 見出しのサイズは行の長さから自動計算して枠いっぱいに寄せる（最大132px）。
- 1画面で主張するのは1つだけ。

### レイアウト4種

| layout | 構成 | 向いている内容 |
|---|---|---|
| `full` | 画像全面＋下部グラデーション | 世界観・ツール紹介 |
| `band` | 上に画像／下に無地の帯 | 文字量が多いリスト系（最も読みやすい） |
| `compare` | 画像2枚を左右分割 | Before/After・2条件の比較 |
| `quad` | 画像4枚を2×2 | 「全部並べた」系 |

どのレイアウトでも左下のロックアップ（ランプマーク＋`LDK LIGHTING LAB` ＋ `@hosh1.921`）は
同じ位置に出る。グリッド全体が1つの作品として見えることを優先している。

## 背景プレートの作り直し

`scripts/instagram/capture-plates.mjs` は日光を OFF にした夜のシーンで、
色温度プリセット4種を同一アングルで撮る。アングルやシーンを変えたいときは、
アプリ側で好みの状態を作ってプロジェクト JSON を保存し、
`public/demo/` に置いたうえでスクリプトの読み込み先を差し替える。

## 表記の注意

サムネイルにもキャプションにも、実照度(lux)・IES/LDT配光・照度計算書を保証する
表現は入れない（[CLAUDE.md](../../CLAUDE.md) の誠実性の不変条件）。
ツール紹介の回には `note` フィールドで免責を1行入れている。
