# Instagram 運用プレイブック（@hosh1.921）

LDK Lighting Lab を「照明を検討中の一般消費者」に届けるための設計。
サムネイルの作り方は [marketing/instagram/README.md](../marketing/instagram/README.md)。

---

## 1. いま届いていない理由

投稿の主語が**ツール**になっている。これが最大の原因で、デザイン以前の問題。

届けたい人（着工前の施主）は「照明シミュレーター」を探していない。探しているのはこれ。

| 検索・保存されるもの | 探していないもの |
|---|---|
| 照明計画 後悔 | 3Dシミュレーター |
| ダウンライト 多すぎ / 数 | パストレーシング |
| 電球色 昼白色 リビング どっち | WebGL / ブラウザで動く |
| 間接照明 費用 | 無料ツール |

つまり **「悩み」を主語にして、ツールは"答えの見せ方"として黙って映す**。
ツール紹介は導線として最後に置くもので、コンテンツの本体ではない。

このアカウントの強みは「同じ部屋のまま条件を1つだけ変えた画が無限に作れる」こと。
写真アカウントには物理的に作れない画で、比較コンテンツと相性が最高。ここに全振りする。

## 2. 前提にしているアルゴリズム（2026年）

- 評価指標が **Views に統一**され、**シェア（DM送信）がリーチ拡大の最重要シグナル**。
  → 「これ見て」と友人・配偶者・営業担当に送りたくなる画を作る。夫婦で決める買い物なので送信されやすい。
- リールは**冒頭3秒で約45%が離脱**。フックが成否の大半を決める。
- 表紙はプロフィールグリッドで **3:4 にクロップ**される。文字は中央 1080×1080 に収める。

出典は本ドキュメント末尾。

## 3. ターゲット

- 30代前半〜40代、注文住宅・建て替え・リノベを検討中
- **着工前〜電気打ち合わせ前の3〜6ヶ月**（照明を決め切る直前がピーク）
- 夫婦2人で意思決定する。片方が見つけてもう片方に送る動きが起きる
- 照明の配置・明るさ・色温度で **「希望する部屋の雰囲気になるか」** を気にしている

## 4. 投稿フォーマット（3種のローテーション）

週3投稿（火・木・金 20:00）。比率は **比較2 : 保存1**、ツール導線は隔週で1本だけ混ぜる。

### A. 比較リール（週2本｜リーチ担当）

同じ部屋で **条件を1つだけ** 変えて並べる。台本は固定でよい。

```
0-3秒   完成画をいきなり出す + 「同じ部屋です」
3-8秒   条件を切り替える（色温度 / 灯数 / 調光）
8-15秒  数字を出す（2700K → 6500K など）
15-20秒 一言の結論 +「保存して打ち合わせに持っていって」
```

ネタは無限に作れる:
- 電球色 vs 昼光色（最初の1本はこれ）
- ダウンライト8灯 vs 4灯＋間接
- 調光100% vs 40%
- 吹き抜けのペンダント、位置を1m動かす
- 20時 / 22時（日光OFF）で見え方が変わる

### B. 保存されるカルーセル（週1本｜保存・シェア担当）

10枚組。1枚目が表紙、2枚目で結論、以降で根拠、最後に保存を促す。
「後で打ち合わせに使う」形にすると保存率が上がる。

- 照明で後悔する人の共通点 5つ
- 色温度 早見表（2700 / 3500 / 5000 / 6500 を実画像で）
- 打ち合わせで聞かれる質問と答え方
- 部屋別・色温度の選び方

### C. ツール導線（隔週1本）

「間取り図を入れると、照明案による部屋の雰囲気を施工前に比べられる」。ここで初めてツールを主語にする。
プロフィールのリンクへ誘導する。**毎回やらない**（宣伝色が濃いとリーチが落ちる）。

## 5. キャプションの型

```
{1行目：表紙と同じ結論を言い切る}

{2〜4行：なぜそうなるかを短く}

うちの間取りだとどうなるか気になる人は、
プロフィールのリンクから自分の間取り図で試せます。
（登録なし・ブラウザだけで動きます）

※雰囲気を比較するための視覚シミュレーションです。
　実際の照度(lux)や仕上がりを保証するものではありません。

#注文住宅 #照明計画 #マイホーム計画中 #家づくり記録
#新築一戸建て #ダウンライト #間接照明 #インテリア照明
#リビング照明 #家づくり
```

- ハッシュタグは **10個前後**。大量付けは効果が薄い。
- 1行目に結論を置く。「こんにちは！」で始めない。
- 免責は毎回入れる（[CLAUDE.md](../CLAUDE.md) の誠実性の不変条件）。

## 6. 表紙のルール（要点）

詳細と実寸仕様は [marketing/instagram/README.md](../marketing/instagram/README.md)。

1. **暗い暖色で行く。** 住宅系フィードは白基調・自然光の写真ばかりなので、
   黒背景＋電球色はスクロール中に明確に浮く。しかも今回の投稿テーマ（夜の照明）と一致している。
2. **文字は1行13文字以内・最大3行。** スマホの一覧では約120px幅で表示される。
3. **1画面に主張は1つ。** 情報を詰めるとどれも読まれない。
4. **毎回同じ位置に同じロックアップ。** グリッド全体が1つの作品に見える＝信頼になる。
5. **画像は必ず自分のレンダー。** フリー素材を混ぜた瞬間にアカウントの独自性が消える。

## 7. 最初の4週間

| 週 | やること |
|---|---|
| 1 | プロフィール文を「照明で後悔しないための〜」に書き換え。比較リール2本＋色温度カルーセル1本 |
| 2 | 比較リール2本（灯数・調光）＋後悔リスト1本 |
| 3 | 比較リール2本＋部屋別カルーセル1本＋ツール導線1本 |
| 4 | 伸びた表紙の型を特定して、それだけを複製する |

判断材料は**表紙のパターン別のView数**。1本ずつ違う型を試して、勝った型に寄せる。

## 8. やらないこと

- 実照度(lux)・IES/LDT配光・照度計算書を保証するような言い方。
  「◯◯lux確保できます」「照度計算します」は**書かない**。
- 他社製品名・メーカー型番を使った比較。
- 施工写真の無断転載。表紙に使う画像は全部このツールで作ったものにする。
